index.html 
<link rel="stylesheet" href="https://xoditor.rameshmaharjan.info.np/dist/xoditor.min.css">
<script src="https://xoditor.rameshmaharjan.info.np/dist/xoditor.min.js"></script>

<textarea id="editor"></textarea>
<script>
  const editor = new Xoditor('#editor', {
    height: '480px',
    defaultFont: 'Arial',
    stickyToolbar: false,
    autoSave: false
  });

  editor.setContent('<p>Make something good.</p>');
  const html = editor.getContent();
</script>
Plain JavaScript. HTML in, HTML out.

Getting started

Download the JavaScript and stylesheet above and serve them with your application. Copy the font stylesheet and its font files if you use the bundled Nepali fonts. The stylesheet and script are also available under /dist/ on this site.

Create a textarea or div, then pass its selector to new Xoditor(). Keep the returned instance to read or replace content.

Configuration

Option Example Purpose
height '480px' Editor height
defaultFont 'Arial' Starting font family
fonts ['Arial', 'Kalimati'] Font menu choices
toolbar ['bold', 'italic', 'link'] Core toolbar commands
ribbon true Ribbon layout
stickyToolbar false Toolbar scroll behavior
autoSave false Enable or disable local autosave
onChange (html, editor) => {} Receive content changes

Content API

editor.getContent()
Returns the current document as HTML.
editor.setContent(html)
Replaces the editor document.
editor.setReadOnly(true)
Changes the editing state.
editor.destroy()
Removes the editor when its host view is unmounted.

A few things to know

Can I use it with React, Vue or another framework?

Use the JavaScript constructor after the host element mounts and call destroy() when it unmounts. These are manual integrations; this project does not ship dedicated framework packages.

What happens when I paste from Word?

The editor accepts rich HTML pasted from the clipboard. Complex Word layouts, fonts and pagination can differ in a browser. Check important documents before saving or printing.

Does the demo save my document to a server?

This playground has autosave disabled and does not submit document content to a server. Reloading the page resets it. Use HTML download to keep a copy.

How do I save content in my application?

Read HTML with getContent() and send it through your own API. Validate and sanitize HTML on your server before storing or displaying content from untrusted users.

Does printing create a server-side PDF?

The print tool opens the browser print flow. Saving as PDF depends on the browser. Server-side PDF generation is a separate integration.
