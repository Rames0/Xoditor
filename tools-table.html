xoditor - Complete Tools & Features Reference

Word-style ribbon preview

Choose a tab to see its tools. Home contains Font, Paragraph, and Editing groups. Table controls appear when you select a cell.

📋 All Available Tools

Tool Name Icon Command Description Usage
📝 TEXT FORMATTING
bold B bold Make text bold Select text and click or Ctrl+B
italic I italic Make text italic Select text and click or Ctrl+I
underline U underline Underline text Select text and click or Ctrl+U
strikethrough S strikeThrough Strike through text Select text and click
subscript X₂ subscript Make text subscript Select text and click
superscript X² superscript Make text superscript Select text and click
🎨 COLORS & FONTS
fontName 📝 fontName Change font family Select from dropdown
fontSize 🔤 fontSize Change font size (1-7) Select from dropdown
foreColor A foreColor Change text color Enter hex color code
backColor 🎨 backColor Change background color Enter hex color code
📐 ALIGNMENT
justifyLeft ⬅ justifyLeft Align text left Click to align current paragraph
justifyCenter ⬌ justifyCenter Center align text Click to center current paragraph
justifyRight ➡ justifyRight Align text right Click to right align current paragraph
justifyFull ⬍ justifyFull Justify text Click to justify current paragraph
📋 LISTS & INDENTATION
insertOrderedList 1. insertOrderedList Create numbered list Click to create/toggle numbered list
insertUnorderedList • insertUnorderedList Create bullet list Click to create/toggle bullet list
indent ➡ indent Increase indentation Click to indent current line/selection
outdent ⬅ outdent Decrease indentation Click to outdent current line/selection
🔗 LINKS & MEDIA
link 🔗 createLink Insert hyperlink Select text, click, enter URL
unlink 🔗 unlink Remove hyperlink Place cursor in link and click
image 🖼 insertImage Insert image Click and enter image URL
📊 TABLES & ELEMENTS
table ⊞ insertTable Insert table Click, specify rows/columns
hr — insertHorizontalRule Insert horizontal line Click to insert line separator
🔧 UTILITIES
removeFormat 🧹 removeFormat Clear all formatting Select text and click to remove formatting
undo ↶ undo Undo last action Click or Ctrl+Z
redo ↷ redo Redo last undone action Click or Ctrl+Y
selectAll ⬜ selectAll Select all content Click or Ctrl+A
print 🖨 print Print document Click or Ctrl+P

⚙️ Configuration Example

const editor = new Xoditor('#editor', {
    height: '400px',
    placeholder: 'Start typing...',
    toolbar: [
        'fontName', 'fontSize',
        'bold', 'italic', 'underline', 'strikethrough',
        'foreColor', 'backColor',
        'justifyLeft', 'justifyCenter', 'justifyRight', 'justifyFull',
        'insertOrderedList', 'insertUnorderedList',
        'indent', 'outdent',
        'link', 'unlink', 'image', 'table', 'hr',
        'removeFormat', 'undo', 'redo', 'selectAll', 'print'
    ],
    fonts: ['Arial', 'Helvetica', 'Times New Roman', 'Courier New', 'Verdana']
});
